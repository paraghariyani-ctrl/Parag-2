# PHF V2
PHF Wedding & Event Crew Booking Manager.

Features:
- Calendar
- Add / edit / delete events
- Multiple members for every crew role
- Roles can be left unassigned
- Client/event/phone search
- Direct WhatsApp and phone call buttons
- Phone Contacts import and permission
- Dark mode
- Offline local storage
- GitHub Actions Android APK build

## Build
Open GitHub Actions and run **Build PHF Android APK**. The workflow creates the Android platform with a valid Dart package name (`phf`) even if the GitHub repository has a name such as `Parag-2`.

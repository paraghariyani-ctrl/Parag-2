# CrewFlow

CrewFlow is a Flutter event and crew management app.

## GitHub upload
Upload the contents of this project to the repository root. The included GitHub Actions workflow automatically creates the Android platform, adds contacts permission, analyzes the project, builds the release APK, and uploads the APK as an artifact.

## Included behavior
- Calendar Add button uses the selected calendar date for a new event.
- Multiple event types per date.
- Multiple dates under one client.
- Client contact picker.
- Team member add/delete.
- Per-date team assignment.
- Unlimited members for every role, including multiple Cinematic/Candid/T. Photo/T. Video/Drone/Helper members in the same event.
- One consolidated WhatsApp message from a team member's chat button containing all assigned dates/events.
- Client event PDF grouped by client and date-wise schedule.
- Profile/brand settings with logo, brand name, contact and email.
- Local device storage.

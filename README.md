# CrewFlow Fresh Project

Fresh Flutter project for:
- Login
- Team Assign
- Quotation page in the left drawer
- Event types: Wedding, Reception, Ganesh Pooja, Haldi, Sangeet, Engagement, Pre Wedding, Baby Shower, House Warming, Corporate Event, Other
- Coverage team assignment
- Deliverables
- Investment / total package
- Reusable Terms & Conditions saved locally
- PDF quotation preview / print
- GitHub Actions APK build

## Upload
Upload the files/folders keeping the exact paths:
- `pubspec.yaml`
- `lib/main.dart`
- `test/widget_test.dart`
- `.github/workflows/build.yml`

Then commit to the `main` branch and run the workflow.

# PHF V2

PHF Wedding & Event Crew Booking Manager.

## Main updates
- Dashboard month changes by left/right swipe.
- Dashboard shows all events for the currently displayed month.
- Floating Add Event button.
- Event cards show client, location, type, full date, time and crew count.
- Add/Edit Event no longer has Event Name.
- Notes is a multiline box.
- Team is added from phone contacts.
- Contacts tab removed.
- Team WhatsApp action lets you choose an event and opens WhatsApp with event details.
- Team assignment uses Assign buttons and an Add Team role option.
- Data is stored locally with SharedPreferences.

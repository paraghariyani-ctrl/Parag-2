# CrewFlow

CrewFlow is an event and team-management app for filmmakers, with branded quotation PDF generation.

## Included
- Calendar and event management
- Team members and role assignment
- Contact import
- Dark mode
- Branded profile/logo
- Quotations with event coverage, deliverables, investment and optional albums
- Editable Terms & Conditions, including saved templates
- Professional quotation PDF with a dedicated T&C area

## GitHub APK build
The repository includes `.github/workflows/build.yml`. Push to the `main` branch or run the workflow manually from GitHub Actions. The workflow creates the Android platform, gets dependencies, analyzes the app and builds a release APK.

# CrewFlow

Flutter event and crew management app.

## GitHub
Upload `pubspec.yaml`, the `lib` folder, and `.github/workflows/build_apk.yml` to the repository root. The workflow creates the Android platform automatically and builds the APK.

## Main features
- Calendar with date-aware Add Event
- Client contact picker
- Multiple event types per event date
- Multiple dates under one client/event
- Crew/team member management with delete
- Per-date role assignment (Candid, Cinematic, T.Photo, T.Video, Drone, Editor)
- Client event summary grouped by client
- Shareable PDF with date-wise event and crew details
- Call and WhatsApp buttons
- Profile/brand settings with logo, brand name, contact and email
- Local device storage

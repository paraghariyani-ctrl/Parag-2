# CrewFlow

A simple offline-first Flutter app for filmmakers to manage events, crew assignments and branded quotations.

## Repository files
- `lib/main.dart` - complete app
- `pubspec.yaml` - dependencies
- `.github/workflows/build.yml` - GitHub Actions Android APK build
- `.gitignore`

The workflow generates the Android platform automatically, so `android/` does not need to be uploaded manually.

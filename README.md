# CrewFlow

CrewFlow is a Flutter app for event calendars, team assignment and professional quotations.

## Included
- Calendar and Event management
- Team Assign with repeatable/unlimited role selection
- Wedding, Reception, Engagement, Pre Wedding, Haldi, Sangeet, Mehndi, Kankotri Lekhan, Ganesh Pooja, Mayra
- Baby Shower, House Warming and Corporate Event
- Login screen UI
- Professional quotation builder
- Multiple requirements per event
- Multiple deliverables with quantities
- Shoot and editing charges with automatic total
- Optional album rows and automatic album total
- Saved Terms & Conditions templates
- Branded quotation PDF with clean black/gold design
- T&C area remains blank when no text is entered
- Android contacts permission
- GitHub Actions APK build workflow

## GitHub
Upload the project contents to your repository. The workflow is at `.github/workflows/build.yml` and can be started from **Actions -> Build CrewFlow APK -> Run workflow**.

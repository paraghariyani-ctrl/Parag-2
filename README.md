# CrewFlow

Professional crew/event management and quotation app.

## Included
- Existing Calendar, Events and Team assignment workflow preserved.
- Drawer menu with **Team Assign** and a separate **Quotation** module.
- Premium dark UI with purple accent styling.
- Login screen / local session.
- Professional quotation builder with event dates, Bride/Groom/Both Side, unlimited crew requirements, deliverable quantities, automatic shoot + editing total, optional albums, saved T&C templates, and branded PDF generation.

## Important
The current Login screen is a local session only. It does **not** yet provide cloud restore after uninstall. Firebase Authentication + Firestore should be connected before shipping the production cloud-sync version.

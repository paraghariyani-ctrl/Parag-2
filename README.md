# CrewFlow

Flutter Android app for event management, team assignment and professional quotations.

Included:
- Dashboard/calendar and event management
- Event types: Wedding, Reception, Engagement, Pre Wedding, Haldi, Sangeet, Mehndi, Kankotri Lekhan, Ganesh Pooja, Mayra, Baby Shower, House Warming, Corporate Event, Other
- Team assignment with unlimited repeated role slots (Cinematic, T. Photo, T. Video, etc.)
- Consolidated WhatsApp message for all dates assigned to a team member
- Quotation module from the drawer
- Bride Side / Groom Side / Both Side per quotation event
- Unlimited requirement quantities per event
- Deliverables with editable quantities
- Shoot + editing charges with automatic total
- Extra albums with quantity, photos per album and price
- Saved Terms & Conditions templates
- Brand profile/logo used in quotation PDF
- Local session/data storage
- Dark mode

## GitHub build
The included `.github/workflows/build.yml` creates the Android platform, installs dependencies, analyzes the app and builds a release APK. The APK is uploaded as the `CrewFlow-APK` workflow artifact.
